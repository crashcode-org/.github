# crashcode

**Driven by curiosity. Built for production.**

I'm Chad, a developer and DevOps engineer. crashcode is my personal lab
for building apps, exploring infrastructure, and automating everyday life.

- **Infrastructure:** infrastructure as code, automated delivery, and learning by operating real systems.
- **Home automation:** Home Assistant brings devices, integrations, and everyday routines together.
- **Private cloud:** eight bare-metal nodes, with Kubernetes and distributed storage.

Most of the code and services stay private. The public lab guide explains what
happens here without opening up the systems behind it.

**[Inside the lab →](https://lab.crashcode.org/)** — explore the hardware, architecture, and decisions.
